Looking Glass B7's DXGI Output5::DuplicateOutput1 design is adapted for single-PC D3D11/NvOFA capture. This branch is experimental and requires Windows x64 runtime verification. It does not copy code from Looking Glass. Native capture is full-display GPU-only Desktop Duplication, with one GPU-to-GPU copy into reusable NvOFA textures; no CPU readback. The V15 original shader hash remains unchanged.
