# FG WGC 320 — CUDA DP4a experiment
Native CUDA unsigned INT8 DP4a block motion estimation, no NvOFA fallback. Based on commit 16b704e2df351997bfdc35f7c319dcaeb34928b2. WGC/DX11 presenter and Dynamic 320 target retained. 8x8 motion grid, half-resolution packed luma, GPU-only D3D11/CUDA interop, subpixel refinement. Compile with VS 2022 x64 and CUDA Toolkit 12.8+ (SM 120). Optional NGX warp still requires its separately supplied runtime. First test with warp off, 60 FPS game cap and Dynamic 320. Experimental; actual GPU latency and displayed cadence not verified.
