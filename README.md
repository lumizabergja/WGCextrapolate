# FG UltraDirect V3 — streamlined pacing
V2's extra D3D12 capture copy queue and per-frame CPU fence wait are removed. D3D11 Desktop Duplication submits one GPU history copy and signals a shared GPU fence; D3D12 graphics and native OFA use that fence. No CPU pixel readback or custom driver. Six history slots, latest-frame mailbox; capture never reuses a slot until its capture/render/flow fences complete. Renderer wakes on capture events or a short high-resolution timer, avoiding coarse Sleep(1) on the active render path. Prediction pacing is anchored to the real present submission; motion horizon remains bounded. Real frames take precedence; obsolete predictions are skipped. Same Mask 320 shader, NvOFA FAST 4x4, cost OFF, Off–x6/Dynamic, 320 target. Runtime GPU compatibility and performance not verified. Use SDR, test an animated window first; compare with V1/V2 under identical conditions.
