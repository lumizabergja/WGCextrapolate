# FG UltraDirect V2 — experimental
Looking Glass-style direct acquired DXGI texture opening into D3D12 (when the driver allows it), a dedicated D3D12 copy queue and six private GPU history textures. The direct path avoids the D3D11 history copy, but still requires a D3D12 history copy so that no acquired texture is used after ReleaseFrame. If opening is unsupported it falls back to the original D3D11 GPU copy. The producer waits for capture GPU completion before releasing the duplication frame, then publishes the newest completed frame. Renderer and NvOFA use pinned private textures; no FIFO, no CPU pixel readback, no game injection, no custom driver. Native D3D12 OFA 4x4 FAST, cost OFF. Existing Mask 320 shader and Off–x6/Dynamic controls retained. The actual path and end-to-end latency remain hardware-dependent.
Inspired by the architecture in Looking Glass host/platform/Windows/capture/D12/backend/dd.c; independently implemented. No Looking Glass code copied.
Use SDR, same GPU, fullscreen borderless or supported fullscreen mode. Run FG.exe and choose the game, Dynamic 320 or x4. Test animated window first. On an error send the exact error. Stop or game exit leaves UI open. Compare to V1 with the same game settings and real FPS. No claim of beating NvFBC without measurement.
