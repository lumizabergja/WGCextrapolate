# FG UltraDirect 320 — experimental
Native D3D12 OFA and presenter, D3D11 DuplicateOutput1 capture into preallocated shared D3D12 textures, SDR BGRA8 only. This format is required by the current shader and optical flow path; native formats other than BGRA8 are not supported. One GPU copy into capture history, real frame copy to backbuffer or scaled shader pass, no CPU pixel readback. Explicit capture, optical flow, render fences; no custom driver or game injection. 320 target, Off–x6 and Dynamic, original Mask 320 shader and UI. Same adapter required. Direct queue for present; no separate D3D12 copy queue. No claim of latency improvement before measurement.
Run FG.exe on Windows 10 22H2 or Windows 11 with an NVIDIA driver supporting Optical Flow SDK 5.0 D3D12. Use SDR and a game entirely on the selected monitor. Select game and Start. Stop or game exit should leave UI open. Use an animated test window first. Report any exact FG error. Compare against original Mask 320 with the same settings, game FPS cap, display mode, and monitor. Actual GPU fence support, shared resource compatibility, pacing, and Independent Flip must be verified on hardware. No virtual display required. Original version remains in its separate branch.
