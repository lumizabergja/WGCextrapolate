# FG WGC 320 – Windows 11 26H2
Direct Windows Graphics Capture of the selected HWND, using the same D3D11 device, two-buffer free-threaded frame pool and latest-frame drain. MinUpdateInterval=0, ReportOnly dirty regions (whole-frame pixels), no cursor or secondary windows. No Desktop Duplication fallback. WGC captures the full selected window; use fullscreen/borderless for game-only pixels. OS capture indicators remain enabled. Existing 320 Hz target, NvOFA 4x4 FAST, extrapolation, presenter, Stop/game-exit behavior and uploaded real-only optional Frame Warp retained. Actual capture FPS, independent flip, latency and Windows 11 26H2 runtime compatibility require testing on your PC.
Build with Windows SDK 10.0.26100 or later and MSVC x64. The Actions artifact contains FG.exe; extract it alongside the original FrameWarpRuntime folder if using Frame Warp. Runtime DLLs are not redistributed here.
