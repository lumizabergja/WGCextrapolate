# FG UltraDirect V4 - single D3D11 device
Experimental build derived from Mask 320, not the D3D12 V3 branch. DuplicateOutput1 (SDR BGRA8; older output interface falls back to DuplicateOutput), one GPU history copy, same-device pre-registered D3D11 NvOFA FAST 4x4, cost OFF, unchanged Mask shader. No CUDA, CPU pixel readback, cross-device handles or custom driver. Release acquired frame immediately before next acquisition, no added GPU flush per frame. Short waitable timer near prediction deadlines. Dynamic fractional slot count and evenly spaced prediction deadlines anchored to actual real-frame submission. No stale prediction FIFO. Real frames prioritized; max frame latency 1. Same Off-x6, Dynamic 320, center radius/feather, original click-through and stop behavior. No independent flip guarantee.
Test SDR animated window first. Select CS2 and 320 target. Start with Immediate present (test) unchecked: standard waitable swapchain, Present(0). Optional checkbox, set before Start, instead uses device max latency 1 and Present(0, DO_NOT_WAIT) with tearing when available; retries a busy slot rather than queueing it. Compare both at 80 native FPS; the immediate option may worsen tearing or pacing. No GPU hardware test in CI; latency and actual frame delivery not verified.
