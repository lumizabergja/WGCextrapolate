# FG WGC 320 — Reflex 2 / low latency
Windows 11 26H2 target. Native WGC D3D11 direct leased textures, NvOFA 4x4 FAST cost OFF, no capture-copy fallback. Dedicated simple real-frame shader; capture mailbox rechecked before OFA to avoid stale prediction work. Real presentation continues if every lease slot is occupied. Dynamic 320, Off–x6, waitable flip-discard maximum latency 1.

Reflex 2 Frame Warp is optional and defaults OFF. OFF uses native D3D11, zero intermediate capture copies. ON restores the original external legacy Streamline D3D12 presenter with shared color, a GPU copy to the swapchain and cross-API fences. It estimates source/late camera pose from raw mouse counts and applies late mouse correction to real frames only. This is not game-integrated Reflex 2; the external camera approximation may produce artifacts and the extra copy can increase latency. No input injection. Runtime compatibility and timing must be tested on the target PC.

The GitHub artifact contains FG.exe and this README. To enable Frame Warp, place the six original FrameWarpRuntime DLLs next to FG.exe under FrameWarpRuntime/. These supplied binaries are not redistributed in the repository. Use Frame Warp OFF as the latency baseline.
