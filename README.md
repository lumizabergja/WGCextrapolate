# FG CUDA NGX Adaptive5 (experimental)

Based on Safe Overlap Luma. NvFBC CUDA, NvOFA 4x4 FAST cost OFF, safe mapped D3D11 buffers, Dynamic 320 and existing UI/center controls remain. Native NGX D3D11 feature 15 is evaluated twice per displayed image (register then late pose) including generated images. No shader warp fallback; disabling Frame Warp restores original presentation. Raw Input uses relative mouse reports at the device's actual rate; set 1000 Hz in mouse software. Adaptive lead 0-5 ms, 1.5-degree prediction clamp, 4-degree total correction clamp, stale and reversed inputs rejected. Source pose uses capture-completion timestamps as a proxy; camera contribution already extrapolated is estimated and subtracted. Assumes CS2 sensitivity 1.5 and yaw/pitch scale .022, synthetic far depth and zero motion vectors. The GPU mask uses screen-space temporal consistency and lower-screen independent-motion evidence, not true game layers; no frozen historical color is composited. HUD and gun switches independent. Mask reused across generated frames, imperfect during low camera motion and complex animations. NGX may not interpret the inferred mask or synthetic inputs as intended. Double evaluation and mask generation can increase latency. No game injection. Runtime is not redistributed: extract the original FrameWarpRuntime.zip beside FG.exe so FrameWarpRuntime/nvngx_latewarp.dll is present. Untick Frame Warp if NGX fails. Actual runtime compatibility and displayed FPS not verified. Build.cmd --blackwell and Test.cmd; AppVeyor fetches public NGX SDK, no game runtime included.
