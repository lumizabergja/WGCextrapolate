# FG CUDA Ultra Late Input (experimental)

Built from Safe Overlap Luma, no NGX or game injection. Dedicated Raw Input thread, device polling rate set in mouse software. Adaptive 0-5 ms prediction with stale/reversal rejection and bounded angular correction. Mouse pose is sampled after DXGI output map, immediately before dispatch. A separate single CUDA kernel replaces estimated historical camera motion with latest input-driven rotational projection and extrapolates residual object motion. On missing flow, Dynamic/static FG can still update camera at its normal output cadence; a 50 ms capture-age limit prevents indefinite stale-image synthesis. No waiting on unfinished OFA; scene cuts and invalid input timestamps use original V15 behavior. Center radius/feather retained. Automatic HUD/gun protection based on color consistency and optical-flow disagreement; estimated per-pixel weights, no frozen past region, incomplete separation during fast motion/zoom or missing data. Assumes unzoomed CS2 sensitivity 1.5, yaw/pitch scale .022, nominal vertical FOV 73.74; source timestamp approximates game input sample time and can cause over/under-correction. Disable Ultra Late Input to use the prior rendering kernel and scheduling. Raw Input receiver remains registered for the session. No guarantee of 3.125 ms mouse-to-photon or actual 320 displayed FPS. Game state/shooting still native FPS. CPU tests verify synthetic input-only response and prediction reversal, not GPU/display latency. Build.cmd --blackwell; Test.cmd. AppVeyor builds Windows and source ZIPs.
