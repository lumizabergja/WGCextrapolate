# FG Reflex + Boost Clean
Derived from Adaptive Mathematical Reflex 2. External NvFBC CUDA capture, NvOFA 4x4 FAST (cost off), V15 extrapolation, Dynamic 320 Hz or Off/x2-x6, original DXGI independent-flip capable presenter, max frame latency 1. NVIDIA NVAPI Reflex + Boost is enabled by default on FG's own device. Frame Warp, AI depth, adaptive camera fitting, mouse history and HUD/gun freezing are removed from the active pipeline. Optional center radius and feather remain for extrapolation, both default 0. No FrameWarpRuntime or TensorRT required. Extract and run FG.exe directly, using compatible NVIDIA driver/NvFBC and Microsoft Visual C++ x64 runtime. Stop or game exit leaves the launcher open. No private memory access or injection. Latency and runtime behavior must be tested on the target machine.
