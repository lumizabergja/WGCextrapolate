# FG CUDA AI Reflex2 Depth — Stage 1 experimental

Actual ZipDepth model path using TensorRT FP16 execution and static 512x384 RGB FP32 input/output. NvFBC capture, overlapping luma, NvOFA 4x4 FAST cost OFF, original CUDA output, direct NGX D3D11 Latewarp and adaptive 0-5 ms input retained. No game injection.

## Install
- Install official Windows x64 TensorRT 10.13 SDK compatible with the pinned headers and CUDA 12.x, Python, Git, and any required NVIDIA runtime DLLs. TensorRT SDK headers are pinned to b8db91e15be2cae4465ac17fab19e0f969e45407; the build prints their version. The matching runtime/engine is required.
- Extract the original FrameWarpRuntime folder beside FG.exe (nvngx_latewarp.dll).
- In PowerShell from the executable folder run: .\Setup-AI-Depth.ps1 -TensorRT 'C:\path\to\TensorRT-10.13.x'
- Setup downloads the official ZipDepth source/checkpoint (pinned commit), exports ONNX with unfold-free checkpoint, builds a device-local FP16 TensorRT plan, and records the runtime DLL path. Run .\Start-AI-FG.ps1. No model, plan, proprietary SDK or runtime DLL is bundled.
- Disable AI depth + NVIDIA Frame Warp to use the original Safe Overlap Luma rendering route (no depth dispatch). If initialization fails, stop, untick and restart.

## Implemented
One in-flight depth inference on a separate low-priority CUDA stream, source sequence ownership until completion. No waiting for unfinished inference; direct presentation when depth is missing. A completed depth tensor is reused for generated frames and mapped through the same approximate flow/confidence coordinates as the original color extrapolator. Depth is written into registered D3D11 output buffers and rendered into the NGX depth texture. RGB preprocessing verified against upstream predictor. No CPU frame readback. TensorRT enqueue occurs on render thread; GPU execution is async, but initialization and host enqueue can stall. Low-priority stream does not guarantee no contention with CS2. Depth estimate is affine-invariant inverse depth, normalized with a sampled per-frame robust range to an arbitrary 0.5–50 scene scale, not actual metric camera depth. No temporal scale alignment yet. Fixed 4:3 model aspect, best suited to CS2 4:3. NGX still uses estimated Raw Input camera rotation, zero MV resource and existing heuristic HUD/gun masks, not trained AI segmentation. No native NVAPI Reflex scheduling yet. No claim of complete native Reflex 2 integration or 3 ms latency. NGX evaluation still requires two evaluations per warped output. GPU/driver/NGX validation required, including whether TensorRT supports the private NvFBC CUDA context. AppVeyor compiles only and runs CPU tests, not GPU inference. 

## Portable release
AppVeyor exports the actual ONNX model at build time. Start-FG.cmd launches with local NVIDIA runtime libraries and generates a GPU-specific engine if missing. The private preparation package must supply the user's original FrameWarpRuntime and official TensorRT/CUDA dependencies; these are not published in this public repo. Once prepared, launch requires no network or Python. GPU inference and NGX compatibility are unverified.

## Guidance update (experimental)
Adds NvOFA backward pixel-space motion vectors at the presenter cadence, jointly writes depth and motion using a CUDA float4 buffer and two D3D11 render targets. Source timestamps and flow are estimates. Previous-depth reuse via optical flow when fresh AI depth is not ready (approximate, no metric calibration); otherwise direct presentation. Temporal range smoothing on consecutive frames. Depth/motion-assisted heuristic gun mask, not semantic AI. Raw Input-derived camera orientation and camera-only NGX cadence when depth is available but flow is not. NVAPI low latency + boost and render/present markers on FG device only, best-effort; opt-in driver sleep with FG_REFLEX_SLEEP=1 because DXGI already paces the queue. No game simulation markers or game injection. No verified actual latency or native CS2 integration. Native camera translation, HUD-less color, true segmentation and metric depth remain unavailable. NGX contract runtime testing required. Update ZIP replaces FG.exe in existing prepared FG folder; retain original model, runtime and GPU-specific plan, start via existing launcher. No model retraining or rebuilding necessary for this update if previous plan is valid.

## Reflex + Boost update
Independent checkbox enabled by default, even with Frame Warp off. Native NVAPI low-latency mode and boost, driver Sleep and render/present markers for FG's D3D11 device. No NVAPI FPS cap. Status label reports API acceptance or rejection, not measured latency or verified GPU clock behavior. FG_REFLEX_SLEEP=0 disables driver Sleep for A/B comparison. Driver rejection leaves the original DXGI pacing available. Reflex disabled on focus loss and shutdown. Update-only artifact reuses previous portable model/engine/runtime; no model re-export required. GPU/driver behavior unverified.

## Fixed freeze update
Replaces temporal HUD and weapon detection with hard, screenshot-relative regions (1650x927 reference, normalized from supplied 1919x1079 screenshot). Both checkboxes default on. Same region predicates in CUDA and HLSL; protected pixels skip extrapolation, guidance is neutral with zero motion, and final NGX composition restores protected pixels from the current captured frame. Mask rebuilt only on settings/size changes. Screen regions refresh with every capture, not frozen permanently; the protected background moves only at source FPS. Weapon envelope fits the supplied AK and hand pose; other viewmodels, recoil, reload or aspect/HUD changes can extend outside it. Native Reflex + Boost retained. No model rebuild needed. CPU mask tests included; actual GPU and visual behavior require runtime validation.

## Late Pipeline update
Dedicated message-only Raw Input worker, above-normal priority, foreground PID gating and short mutex-protected history lookups. Sample input after source registration, estimate prediction lead from recent CPU NGX submission cost and half output period, capped at one output interval and 5 ms. This is not actual scanout timing. Driver sleep before final timestamp, skip redundant waits adaptively (FG_REFLEX_SLEEP=0 disables, =1 forces). Display clock skips elapsed deadlines after submission. CUDA fused color/depth/motion path shares flow and confidence reads; batch graphics map/unmap on existing registered D3D11 buffers. AI submission deferred if display is due; reuse at most one previous real depth with completed flow, neutral guidance on scene cut. Fixed HUD/gun coordinates and final restoration unchanged. Two NGX evaluations retained until runtime contract validated; no unsafe private single-call shortcut. Existing AI engine/runtime compatible. CPU tests and compile via CI; runtime and latency not verified.
