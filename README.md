# FG Native12 Both Modes (experimental)
Independent native D3D12 test, not a replacement for the current D3D11 build. WGC uses D3D11On12, direct underlying texture leases, native fence-based NvOFA 4x4 FAST with cost off, common D3D12 shaders, frame latency 1, Dynamic 320, same radius/feather and fully opaque layered NOREDIRECTIONBITMAP presentation. Warp ON alone loads the original Streamline runtime, retains its HUD-less copy and mask, and preserves real-only late correction. Warp OFF does not load Streamline. No D3D11 capture or OFA fallback. Driver compatibility, Independent Flip, and latency must be measured on Windows. If WGC unwrap or registration fails, report the error. Copy original FrameWarpRuntime folder beside FG.exe if not included in CI artifact.
