# FG Native DX11 NGX Latewarp diagnostic
This is a standalone synthetic-image probe, not a new FG build. Copy your original FrameWarpRuntime folder alongside FG-NGX-DX11-Probe.exe and run Test.cmd. Close the game first. No injection, D3D12 bridge, Streamline or fallback. The probe uses the public NVIDIA NGX SDK and a unique custom project ID. It attempts feature 15 creation, then synthetic evaluation with read-only color input shared as HUD-less color (no additional color copy), separate output and center mask. The evaluation keys are adapted from a community D3D12 implementation and are unverified on D3D11; failure does not prove the backend is impossible. The result log shows the last stage and error codes. A successful API call alone is not proof of visible warp; readback compares the two frames. Return the text log. No actual game latency is measured. The current FG app is unchanged.
Sources: https://github.com/NVIDIA-RTX/Streamline_Sample/blob/main/src/NGXWrapper.cpp and https://github.com/xPoiler/Reshade-Asynchronous-Reprojection/blob/main/src/presenter/latewarp12.cpp.
